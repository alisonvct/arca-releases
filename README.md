# Arca — versões

Instaladores do Arca, um media center pessoal baseado em addons. Este repositório só contém os
arquivos de cada versão; o código-fonte é privado.

- **Windows:** baixe `Arca-Setup-<versão>.exe` na versão mais recente. O app se atualiza sozinho
  a partir daqui. Como o instalador não é assinado, o Windows mostra "Editor desconhecido": clique
  em *Mais informações → Executar assim mesmo*.
- **TV LG (webOS):** `app.arca.tv_<versão>_all.ipk`, instalado pelo Developer Mode.
